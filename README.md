# Great Lakes Sediment Monitoring Dashboard

Interactive dashboard for visualizing Great Lakes sediment monitoring data from Environment and Climate Change Canada.

🔗 **Live Dashboard**: [https://tylerprlake.github.io/great-lakes-sediment-dashboard/](https://tylerprlake.github.io/Great-Lakes-Multimedia-Dashboard/)

## Features

- Surface/Core sample type toggle
- Interactive maps with station locations
- Core profile visualization with depth charts
- Trend analysis over time
- Station comparison charts

## Data Updates

Data is automatically fetched from ECCC every Monday at 2 AM UTC.

## Manual Update

To manually update data:
1. Go to the "Actions" tab
2. Select "Fetch Great Lakes Data"
3. Click "Run workflow"
